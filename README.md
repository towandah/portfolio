# Marigui — portfolio

Static site (GitHub Pages). Pages are generated by `tools/build.py` from the photos in `img/`.

## Add or remove photos

1. Drop the HD WebP files (2560 px long edge) in `img/<folder>/`.
   File names must follow `<series>-<nn>.webp`, e.g. `surf-indo-09.webp`.
2. To create a new series or change labels, edit `SECTIONS` in `tools/build.py`
   (series prefix → series title, section intro, cover image).
3. Rebuild and publish:

```
python3 tools/make_thumbs.py     # 800 px thumbnails for the walls (only missing ones; --force to redo all)
python3 tools/build.py           # regenerates the HTML pages
git add -A && git commit -m "Update photos" && git push
```

`img/mapping.csv` keeps the correspondence between the original camera file names and the site names.

## Structure

- `index.html` — home: wordmark, 5 section tiles, "Selected" wall (`img/featured/`), About, Work together, contact.
- `surf.html`, `vanlife.html`, `landscapes.html`, `cities.html`, `projects.html` — one masonry wall per series, stacked; full-screen viewer (HD image, arrows / swipe / keyboard).
- `assets/site.css`, `assets/site.js` — shared styles and behaviour.
- Portraits of the About block: `img/me-1.webp` and `img/me-2.webp`.
- Contact form: set `FORMSPREE` in `tools/build.py` to your Formspree endpoint (`https://formspree.io/f/xxxx`) and rebuild.
